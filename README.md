# Norigoni Daily OS

鬼の100日（2026/11/21〜2027/2/28）の、個人用の習慣と営業のアプリです。

- `index.html` 1ファイルで動きます（HTML / CSS / JavaScript）。
- 入力した記録は、開いた端末のブラウザ（LocalStorage）にだけ保存されます。このリポジトリには入りません。
- 取引先の住所・電話番号は入れていません。連絡先は別のスプレッドシートで管理します。

## スマホで使う

GitHub Pages で公開した URL を iPhone の Safari で開き、共有ボタンから「ホーム画面に追加」します。
